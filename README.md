# CarValAI

Check it out here: [CarValAI](https://www.carvalai.co.uk)

A full-stack Car valuation application powered by a Machine Learning model.

## Features
- **AI-powered:** An XGBoost Regressor model is used to value a vehicle, given details regarding its age, condition and specification
- **5 Year Value forecast:** Graph of the vehicle's value over the next 5 years, estimating a mileage of 8k miles/yr
- **Fast and Accurate:** Mean Average Percentage Error of only 7.7%
